## Why This Order

### 1. PHSA (Vancouver, hybrid) — posted 2026-07-09
The posting explicitly names Power BI and Excel on large datasets, plus dashboarding, data quality, and indicator reporting — the exact portfolio story this repo tells. It is a casual Talent on Demand role, which is the classic entry gateway into a provincial health authority: successful casuals transition into permanent PHSA roles. Lead with the access-coverage dashboard and the province-level reporting narrative.

### 2. Partners Community Health (Mississauga) — posted 2026-02-25
Strongest tool overlap of the batch: SQL, Power BI, DAX, KPI scorecards, executive dashboards, all in a healthcare/long-term-care organization. The title is senior (5-8+ years asked), so this is a stretch application — but stretch applications with an exact stack match and a public proof portfolio are worth one focused cover note. Lead with both dashboards and the SQL pipeline.

### 3. Sunnybrook — Project REACH (Toronto) — posted 2026-02-28
Hospital Information System implementation BA at a top academic hospital. Asks 5+ years of healthcare IT BA experience, so high stretch — but requirements gathering, workflow mapping, and stakeholder documentation are demonstrable through this repo's process docs and validators. Lead with the wait-times analysis and the documentation discipline visible in the repo.

### 4. Costello Medical (Vancouver, hybrid) — posted 2026-07-09
Health economics and market access consultancy with rolling monthly start dates through 2026. Asks a science degree plus 2 years agency experience; no visa sponsorship (existing right to work in Canada required). The company also hires entry-level Analysts, so a strong application can be redirected to the junior track. Lead with the healthcare access comparison across provinces and written communication quality.

### 5. Sunnybrook — PMO / O365 migration (Toronto) — posted 2026-02-27
Weakest analytics overlap (O365 migration focus) but still a hospital BA title with requirements, gap analysis, and process documentation at its core. Apply last; the contract runs to 2026-11-16 so timing matters.

## Honest Positioning Note

None of the five are true junior postings — entry-level healthcare BA roles were not in the live feed on 2026-08-16. Each row in `tracker/applications.csv` carries an honest stack-match score and a stretch note so the tracker stays truthful. The counter-strategy is proof-of-work: a public portfolio with real Canadian healthcare data, validated outputs, and a visible commit trail closes part of the experience gap that a resume alone cannot.
